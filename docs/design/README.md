# Design notes along the way

Dated working documents recording *why* the resonant lattice is shaped the way
it is — each written at the moment a design decision was actually made, in
response to a real problem observed in live operation. They are collected so
that the path here makes sense to anyone willing to really follow it.

Convention: `YYYY-MM-DD-short-title.md`, one decision or insight per document,
written to be readable standalone. Personal and operational details are kept
out; the engineering is kept intact.
